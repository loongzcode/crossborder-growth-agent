# 合成样例数据

此目录只保存用于开发、测试和面试演示的合成数据，不包含任何真实商家、消费者或广告账户信息。

- `tiktok_ads_sample.csv`：包含标题行、中文表头、未知列和一条质量异常数据，可直接上传到广告报表预检接口。
- `orders_sample.csv`、`products_sample.csv`：订单明细和商品主数据。
- `costs_sample.csv`、`inventory_sample.csv`：成本口径和库存快照。
- `refunds_sample.csv`、`reviews_sample.csv`：退款和不含消费者身份信息的评价。
- `currency_rates_sample.csv`：人为构造的汇率，不代表真实市场行情。
- `creatives_sample.csv`：仅包含虚构的素材元数据和地址，不包含素材文件。
- 样例中的金额、订单、广告系列和经营表现均为人为构造，不代表真实业务成果。
