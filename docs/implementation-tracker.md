## 2. 关闭规则

- `[x]`：代码或文档已经落库，并且对应静态检查、单元测试、集成测试或人工验收已通过。
- `[ ]`：尚未实现、只完成了接口定义、仅有占位页面，或缺少关键环境验收。
- 一个需求如果只完成一部分，必须拆成多个原子任务，不能关闭整个需求。
- 每次功能提交必须同步更新本文件，并在任务项后填写代码、测试或文档证据。
- 真实平台接入、真实数据库联调、Agent 推理、前端业务页面不得用模拟器、配置类或路由占位冒充完成。
- 进度只按任务是否验收统计，不按代码行数或文件数量统计。

## 9. 九个 Agent 业务能力

### 9.1 Supervisor Agent

- [ ] 根据请求和数据状态选择需要运行的领域 Agent。
